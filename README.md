# 🤖 AI Adaptive LMS for Atomcamp

## 📌 Problem Statement

Atomcamp is an emerging tech education ecosystem offering bootcamps and learning programs across Pakistan. As the learner base grows, a major challenge arises: every learner has different learning styles, skill levels, engagement patterns, and learning speeds, yet traditional LMS platforms treat all learners the same.

This lack of personalization leads to:
- Low learner engagement
- Higher dropout rates
- Limited visibility into struggling students
- Generic learning experiences
- Difficulty in tracking skill gaps

Our project solves this problem by building an AI-powered Adaptive Learning Management System for Atomcamp that provides personalized learning support, intelligent analytics, AI mentorship, and data-driven decision-making for students, instructors, and administrators.

---

# 🚀 Features

- AI Mentor chatbot powered by Gemini AI
- Personalized student learning dashboard
- Instructor analytics and learner monitoring
- Admin analytics dashboard
- AI-generated learning insights and recommendations
- Skill gap and dropout analysis
- Adaptive quiz system
